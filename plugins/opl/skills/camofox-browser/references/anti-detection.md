# Capability limits

Camoufox is a Firefox-based browser with fingerprint configuration at the browser-engine level. These features do not establish that a site cannot detect automation or that navigation will succeed.

Inspect the installed Jo server's launch configuration before describing WebRTC blocking, proxy behavior, geolocation, locale, humanization, or display mode as active. Defaults differ between versions and installations. A proxy does not establish anonymity or change the scope of a website whitelist.

Select headless or desktop mode through the launch interface supported by the installed package. Do not assume that the community skill's older `CAMOFOX_HEADLESS` or `HTTPS_PROXY` examples configure a current Jo server.

When a browser option is rejected, check the wrapper version and the native browser schema. Keep validation enabled and resolve the specific compatibility mismatch.

Use [Jo's current README](https://github.com/jo-inc/camofox-browser) and the installed launch code as the authority for active server options. Use [Camoufox's documentation](https://camoufox.com/) for engine capabilities. Distinguish a configured option from behavior observed during the task.
